# 系统功能简述（界面 · 最新）

面向 PD-L1 / TPS 的全切片交互分析原型：**选病例 → 浏览全图与 patch → 结合分布与 ROI 读图 → 可选对话助手**。

## 布局概览

| 区域 | 功能 |
|------|------|
| **顶栏** | 病例与数据源切换、全局入口 |
| **左侧栏 · 上（Specimen Explorer）** | **病例卡片列表**：缩略图；**ID**（病例目录名）；**TPS** 为全图 patch 平均预测 TPS（百分比）；**状态标签**按均值分档——**High PD-L1**（均值 ≥50%）、**Elevated**（10%～50%）、**Low expressors**（均值低于 10%）；若有导出 patch 则显示 **Processed**。列表默认按 TPS 从高到低排序，便于优先查看高表达病例；可刷新扫描数据目录。 |
| **左侧栏 · 下** | **Patch Gallery**：当前病例 patch 缩略列表，可按 **TPS 临床分档**（如 ≥50%、10–50% 等）筛选，点击与主视图联动。 |
| **中间 · 上** | **全切片 Deep Zoom**：缩放平移；patch 网格叠加；TPS KDE 热力；可选 **局部 ROI** 框选与工具栏。 |
| **中间 · 下** | **TPS 分布条**：全图 TPS **直方图**（含 ROI 叠加对比时可切换）；**全图 TPS 分档占比条**（各档 patch 数量比例）；**ROI 选区统计**面板。 |
| **右侧栏** | **选中 patch** 的多层预览（原图 / 细胞标注 / 热力等）与数值详情。 |
| **浮动按钮** | **对话式助手**：基于当前病例与选中内容的问答（可选）。 |

## 左侧上栏（病例卡片）字段一览

- **ID**：`data/<病例文件夹名>`，用于唯一标识病例。  
- **TPS: xx.x%**：该病例全部有效 patch 的 **平均预测 TPS**（展示层面与列表排序一致）。  
- **High PD-L1 / Elevated / Low expressors**：由上述均值落入的粗分层级，便于快速扫一眼「高表达 vs 低表达」。  
- **Processed**：表示 manifest 中已有导出 patch 数量信息时的提示标签。

## 一句话

左栏上按 ID、TPS 与 High PD-L1 等标签挑病例；下栏按分档浏览 patch；中为全切片及 TPS / ROI 分析；右栏看选中 patch；可选 AI 辅助读片。
