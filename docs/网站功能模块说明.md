# TPS-Vis（web-agent）网站功能模块说明

本文档描述当前前端应用（`web-agent`，Next.js App Router + React）的**界面分区、交互链路、状态字段与 API**，与源码保持一致，便于对接论文「系统架构 / 交互设计 / 方法实现」小节。

**读者与用途**：实现对照、文档Review、向 ChinaVis / IEEE *TVCG* 类稿件迁移时的术语对齐。

**技术栈摘要**

| 层级 | 选型 |
|------|------|
| 框架 | Next.js（`src/app`），客户端组件 `"use client"` |
| 主阅片 | OpenSeadragon，manifest 提供金字塔 / DZI `tileSource` |
| 全局状态 | Zustand（`src/lib/store.ts` → `useViewerStore`） |
| 样式 | Tailwind CSS；暗色临床工作台风格 |
| 统计与可视化 | 部分 Canvas（TPS 直方图柱、热力图）；DOM + SVG（指标条、混合条） |

**文档约定**

- **组件路径**除非另有说明，均相对于 `web-agent/src/`。
- **Store 字段名**与 `ViewerState` 一致（camelCase）。
- **「世界坐标」**：与 manifest / OSD 图像像素对齐的 ROI 矩形（`WorldRect`：`x,y,w,h`）。

## 1. 页面整体布局

**入口**：`src/app/page.tsx`。

根节点为 `flex h-screen flex-col`：**顶栏**占一行，下方 `flex-1` 为三列主体；最外层 **`AiAssistantFloating`** 通过 Portal 挂在 `document.body`，不参与文档流，叠在最上层（`z-[100]`）。

### 1.1 区域划分

| 区域 | 组件 | 职责摘要 |
|------|------|----------|
| 顶栏 | `components/topbar/TopBar.tsx` | 品牌与副标题，无业务控件 |
| 左栏 | `components/side/left/LeftSidebar.tsx` | 上：**标本浏览器**；下：**Patch 图库**。上下各占约一半高度（`flex-1`） |
| 中栏 | `components/side/left/LeftColumn.tsx` | 上：**主阅片器** `flex-[5]`；下：**TPS 分布总览** `flex-[2]` |
| 右栏 | `components/side/right/RightColumn.tsx` | 上：**选中 patch 预览带** `flex-[5]`；下：**选中 patch 详情** `flex-[2]` |
| 浮动 | `components/side/right/AiAssistantFloating.tsx` | FAB + 可拖拽对话面板 |

### 1.2 左栏尺寸与滚动

`LeftSidebar`：`w-fit min-w-[360px] max-w-[440px]`，右侧 `border-r`，背景半透明。内部两段均为 `min-h-0 flex-1 overflow-hidden`，各自内部再 `overflow-y-auto`，保证病例列表与图库在窗口缩小时**独立纵向滚动**，互不挤压布局。

### 1.3 中栏与右栏纵向对齐

`LeftColumn` 与 `RightColumn` 均采用 **`flex-[5_1_0%]` / `flex-[2_1_0%]`**，因此主阅片区高度与右侧预览带高度一致，下方 TPS 条与右侧详情区高度一致——论文插图若要画「三分区对齐」，可直接引用 **5:2** 比例。

### 1.4 右栏宽度逻辑

首次渲染前 `ResizeObserver` 尚未测量时，`aside` 使用 `w-[clamp(360px,28vw,500px)]` 占位。测量预览带高度 `h` 后，栏宽设为 **`round(h/2)` px**：预览带内叠放 **两行**方形 tile，tile 边长 = `h/2`，栏宽与双列预览对齐，避免多余水平留白（见 `RightColumn.tsx` 注释）。

## 3. 标本浏览器（Specimen Explorer）

**组件**：`src/components/side/left/SpecimenExplorer.tsx`。

### 3.1 数据加载

- 首次挂载若 `caseListStatus === "idle"`，自动调用 **`loadCaseList()`**（`GET /api/cases`）。
- `caseListStatus`：`idle` → `loading` → `ready` | `error`；错误时 `caseListError` 可供扩展 UI（当前卡片区主要依赖列表是否为空）。

### 3.2 卡片内容与排序

- 列表来自服务端扫描数据根下的 **分析实例**（`CaseSummary[]`）。
- 展示前在客户端按 **`meanPatchTps` 降序** 排序，便于优先浏览模型均值较高的病例。
- 单卡包含：**缩略图**（`thumbnailRelative` → `caseFileRelativeUrl` 拼 URL）、**caseId**、**格式化后的平均 TPS 百分比**（`formatTpsPercentDigits`）、**状态短语**：
  - `meanPatchTps ≥ 0.5` → `High PD-L1`
  - `≥ 0.1` → `Elevated`
  - 否则 → `Low expressors`

### 3.3 交互与选中态

- 点击卡片触发 **`setCase(caseId)`**（异步）：加载 manifest、清空选中 patch、重置图库分页、清空对话与 ROI 等（详见 §12 联动表）。
- 当前病例卡片使用 **sky 色系边框 / 背景 / ring**（`specimen-card--selected`），缩略图可加 glow 类名突出。

### 3.4 Import Source Directory

- 工具栏按钮 **`FolderInput`**：在支持 **`window.showDirectoryPicker`** 的环境下尝试唤起目录选择（用户取消则静默）；**无论成功与否**随后都会 **`await loadCaseList()`**，用于通知服务端重新扫描数据根（具体是否监视用户所选目录取决于服务端实现；前端语义为「刷新实例列表」）。
- 加载中按钮 `disabled`，避免重复触发。

### 3.5 空态与加载态

- `loading && caseList.length === 0`：文案 `Loading…`
- `caseList.length === 0`：提示将病例目录放到数据根下并执行 Import

## 4. Patch 图库（Patch Gallery）

**组件**：`src/components/side/left/PatchGallery.tsx`。

### 4.1 数据源与过滤

- 使用当前 **`manifest.patches`**，先经 **`patchesWithCellsForTps`** 过滤：无细胞级 TPS 可用数据的 patch **不参与图库与下游直方图统计**（与系统其他模块一致）。
- **分档**：仅显示 `galleryBucket` 对应临床档（`Negative` / `TPS_1` / `TPS_10` / `TPS_50`，样式 `BUCKET_STYLES`）。
- **ROI**：若存在 **`localRoi`**，只保留与 ROI **世界矩形相交**的 patch（与 `patchesIntersectingRect` 一致）。

### 4.2 排序与分页

- 排序键：**预测 TPS**（`patchPredTps`），顺序由 **`gallerySort`** 控制（`desc` | `asc`，默认 `desc`）。
- 侧栏模式每页 **`GALLERY_PAGE_SIZE_SIDEBAR`（当前为 8）** 条；底部分页控件切换 **`galleryPage`**。
- **重置页码**：切换 **`galleryBucket`**、**`gallerySort`**、**病例**、以及 Store 内若干联动（如 `setGalleryBucket` 实现里 `galleryPage: 0`）会将分页归零，避免跨筛选空白页。

### 4.3 交互

- 单击条目：**`setSelectedPatch`** + **`flyToPatch`**，主视图飞行到对应 patch，右侧加载细胞数据。
- **`variant="sidebar"`**：左栏下半区竖向列表 + 分页。
- **`variant="grid"`**：预留网格分页布局（页大小常量可与侧栏不同）。

### 4.4 与 TPS 总览的联动

直方图卡片上点击某一 **临床档位背景带** 会调用 **`setGalleryBucket(bucket)`**，从而图库只显示该档 patch（见 §6）。

## 6. TPS 分布总览条带（Tps Distribution Bar）

**组件**：`src/components/side/left/TpsDistributionBar.tsx`。统计内核：**`src/lib/tpsHistogram.ts`**。

### 6.1 用户可见功能（论文「界面」表述）

- **卡片占位**：中栏下方约 **2/7** 高度，独立滚动容器 `overflow-y-auto`，内部是多区块仪表盘（直方图 + 档位带 + Hilbert 条 + ROI 面板等）。
- **直方图**：
  - 数据层：**0.1%** 细粒度 bin（`TPS_HISTOGRAM_BIN_COUNT` / `buildTpsPercentBins`）。
  - 绘制层：**等像素柱宽**（`buildEqualPixelHistogramPlan`，最小柱宽约 **4px**，`HISTOGRAM_MIN_BAR_PX`，柱数上限约 **480**）。
  - 横轴：与 **临床四档比例带宽** 共享 **`blendTpsAxes` / `createProportionalTpsAxis`**，柱边界由比例尺逆映射得到（`aggregateFineBinsByTpsEdges`），保证 **档内柱计数之和 = 该档 patch 数**。
  - 纵轴：**patch 计数**；全片柱顶留白比例 **`WS_FILL_RATIO = 0.9`**；ROI 模式 **`ROI_FILL_RATIO = 0.8`**，配色 `ROI_FILL` / `ROI_STROKE`。
- **模式切换**：无 ROI 或 ROI 内无 patch → **全片** patch 集合；否则 → **仅 ROI 内** patch。**不**在同一视图双层叠加全片与 ROI 柱，以免误读。
- **档位占比条（背景带）**：四档 patch 占比可视化；点击某一档 → **`setGalleryBucket`** → 左侧图库同步筛选。
- **HilbertSpatialStrip**：全片四档混合比例条（§7）。
- **SelectionRoiPanel**：嵌入 Scalar 指标条（§8）。
- **布局稳健性**：`ResizeObserver` 读取多条宽度来源，避免 flex 初渲染宽度为 0 导致 Canvas 尺度错误。

### 6.2 计算方法与符号（论文 Methods 取向）

以下与原 §6.1 公式一致，便于稿面迁移；实现对应 **`tpsHistogram.ts`**、**`TpsDistributionBar.tsx`**。

#### 6.2.1 基本记号

| 符号 | 含义 |
|------|------|
| \(\tau\) | 模型输出的 patch 级 TPS，\(\tau\in[0,1]\)（与代码 `patchPredTps` 一致） |
| \(p\) | TPS 百分比，\(p=100\tau\) |
| \(\mathcal{P}\) | 参与统计的 patch 集合（含细胞级 TPS 的过滤子集） |
| \(W_{\mathrm{plot}}\) | 绘图区水平像素宽度（`PLOT_W`） |
| \(x_0\) | 绘图区左边界横坐标（`PX0`） |

#### 6.2.2 细粒度直方图（数据层，固定 0.1% 分辨率）

将每个 patch 归入离散索引 \(k\in\{0,\ldots,K\}\)，\(K=1000\)：

\[
k \;=\; \mathrm{clamp}\bigl(\mathrm{round}(1000\,\tau),\,0,\,1000\bigr).
\]

第 \(k\) 个细 bin 对应的标称 TPS 百分比区间为半开区间（与聚合实现一致）

\[
I_k \;=\; \bigl[10k/K,\;10(k+1)/K\bigr) \;=\; \bigl[k/10,\,(k+1)/10\bigr) \quad (\%).
\]

区间宽度 \(\Delta p_{\mathrm{fine}} = 0.1\%\)。令 \(c_k\) 为落入该索引的 patch 个数（`buildTpsPercentBins`），则 \(\sum_k c_k = |\mathcal{P}|\)。

#### 6.2.3 比例尺横轴（可视带宽，背景带与刻度）

临床四档 \(b\in\{\mathrm{Neg},\mathrm{T1},\mathrm{T10},\mathrm{T50}\}\) 对应 TPS 分段边界 \(0,1,10,50,100\)（%）。记档内 patch 数为 \(n_b\)，\(N_{\mathrm{tot}}=\sum_b n_b\)。各档在横轴上分配的像素宽度为

\[
W_b \;=\;
\begin{cases}
\dfrac{n_b}{N_{\mathrm{tot}}}\,W_{\mathrm{plot}}, & N_{\mathrm{tot}}>0,\\[6pt]
\dfrac{1}{4}W_{\mathrm{plot}}, & N_{\mathrm{tot}}=0\ \text{（均匀退化）}.
\end{cases}
\]

比例映射 \(f_{\mathrm{prop}}:[0,100]\to[x_0,x_0+W_{\mathrm{plot}}]\) 为分段线性（档内 \(p\) 均匀拉伸到该档像素宽度），即代码 `createProportionalTpsAxis` 中的 `mapTpsToX`。界面动画时在两种轴实例间线性混合：

\[
f_{\mathrm{blend}} \;=\; (1-\lambda)\,f^{(1)} \,+\, \lambda\, f^{(2)},\qquad
W_b^{\mathrm{blend}} \;=\; (1-\lambda)\,W_b^{(1)} \,+\, \lambda\, W_b^{(2)},
\]

其中 \(\lambda\in[0,1]\) 为插值系数（`blendTpsAxes`）。**直方图柱宽与位置** 同样基于该比例尺：在屏幕 \(x\) 轴上等像素分割，柱边界由 \(f_{\mathrm{blend}}^{-1}\) 给出（见 6.2.4），保证柱与背景临床带 **逐像素对齐**。

#### 6.2.4 等像素柱与可视带宽驱动的自适应精度（核心）

为消除「柱 \(x\) 映射与背景带 \(x\) 映射不一致」的视觉错位（早期版本曾以 \(\sigma_b\cdot W_b\) 加权累积构造柱边界，会让一部分高档柱被画在低档背景内），最终方案是：**柱的 \(x\) 划分与比例尺背景带完全共享一套映射**，由「可视带宽」单方面决定每柱代表的 TPS 精度（敏感度权重不再独立施加于 \(x\) 上）。

**柱数与等像素柱宽**：

\[
N_{\mathrm{bar}} \;=\; \mathrm{clamp}\Bigl(\Bigl\lfloor \frac{W_{\mathrm{plot}}}{w_{\min}} \Bigr\rfloor,\,1,\,N_{\max}\Bigr),
\qquad
W_{\mathrm{bar}} \;=\; \frac{W_{\mathrm{plot}}}{N_{\mathrm{bar}}}.
\]

默认 \(w_{\min}=4\)（CSS px，可调）、\(N_{\max}=480\)（`buildEqualPixelHistogramPlan`）。

**柱 TPS 边界**：屏幕等像素采样后由比例尺逆映射回 TPS 百分比：

\[
x_i \;=\; x_0 + i\, W_{\mathrm{bar}},\qquad
e_i \;=\; f_{\mathrm{blend}}^{-1}(x_i),\qquad i=0,\ldots,N_{\mathrm{bar}}.
\]

由此第 \(i\) 根柱覆盖 \(p\in[e_i,e_{i+1})\)，**柱与档背景带的边界对齐**：落在 \(b\) 档背景上的所有柱集合 \(B_b\) 满足

\[
\bigcup_{i\in B_b}[e_i,e_{i+1}) \;=\; [p_b^{\mathrm{lo}},\,p_b^{\mathrm{hi}}).
\]

**每柱 TPS 精度（自适应于该档的可视带宽）**：在档 \(b\) 内，柱数 \(K_b = W_b / W_{\mathrm{bar}}\)，故

\[
\Delta p_i \;=\; e_{i+1}-e_i \;=\; \frac{p_b^{\mathrm{hi}}-p_b^{\mathrm{lo}}}{K_b}
\;=\; \frac{p_b^{\mathrm{hi}}-p_b^{\mathrm{lo}}}{W_b}\, W_{\mathrm{bar}}
\quad (\,i\in B_b\,).
\]

即「档内 patch 多 ⇒ 可视带宽 \(W_b\) 大 ⇒ 该档 TPS 精度 \(\Delta p_i\) 细」，与 \(\sigma_b\) 解耦。\(\sigma_b\) 若仍需引入（如未来用户偏好），可作用于 \(W_b\)（重定义档宽度）而非 \(x\) 映射，从而保留对齐性。

#### 6.2.5 细 bin 到柱上的质量守恒聚合

对第 \(i\) 根柱，区间 \([e_i,e_{i+1})\) 与细 bin 区间 \(I_k\) 求交，按比例分配计数（长度与 \(\Delta p_{\mathrm{fine}}=0.1\) 归一）：

\[
\tilde{c}_i \;=\; \sum_{k=0}^{K} c_k \cdot
\frac{\mathrm{length}\bigl(I_k \cap [e_i,e_{i+1})\bigr)}{\Delta p_{\mathrm{fine}}}.
\]

即 `aggregateFineBinsByTpsEdges`；当柱边界与细 bin 对齐时退化为整数求和，否则为重叠比例加权。该聚合保证 **质量守恒**：\(\sum_i \tilde{c}_i = \sum_k c_k = |\mathcal{P}|\)，于是 **档 \(b\) 内柱面积之和**

\[
\sum_{i\in B_b}\tilde{c}_i \;=\; n_b,
\]

即每个临床带（背景颜色区）内 **直方图柱的总质量恰好等于该档 patch 数**，与第 7 节占比条带的数字一致。

#### 6.2.6 纵轴尺度与柱高（顶边留白）

记 \(H_{\mathrm{plot}}\) 为绘图区高度，\(\tilde{c}_{\max}=\max_i \tilde{c}_i\)（全片或 ROI 各自的聚合序列）。为使 **最高柱不占满整幅高度**，引入填充比 \(\rho\in(0,1]\)，纵轴显示上界取

\[
Y_{\max} \;=\; \frac{\tilde{c}_{\max}}{\rho}.
\]

柱 \(i\) 的绘制高度（像素）为

\[
h_i \;=\; \min\!\left(H_{\mathrm{plot}},\;\frac{\tilde{c}_i}{Y_{\max}}\,H_{\mathrm{plot}}\right).
\]

实现中：**全片** \(\rho=\rho_{\mathrm{ws}}=0.9\)（`WS_FILL_RATIO`）；**ROI 模式** \(\rho=\rho_{\mathrm{roi}}=0.8\)（`ROI_FILL_RATIO`）。该写法与 TVCG 类文中常见的「normalized display range」表述一致：通过 \(\rho\) 留出顶部裕量，避免单 bin 贴顶造成饱和感。

#### 6.2.7 混合条（与直方图一致的档位占比）

第 7 节 Hilbert 条带各档水平宽度 \(\omega_b\) 满足 \(\omega_b \propto n_b\)，\(\sum_b \omega_b = W_{\mathrm{plot}}\)，即 **占比条形图** 的标准编码；与本节 \(W_b\) 同源计数但用途为 **类别混合可视化**，非 TPS 连续轴。

## 7. 全片档位混合条（Hilbert Spatial Strip）

**组件**：`src/components/side/left/HilbertSpatialStrip.tsx`。

### 7.1 视觉编码

- 名称保留历史（Hilbert）；**当前实现**为从左到右：**Negative → TPS_1 → TPS_10 → TPS_50**。
- 每一档 **flexGrow ∝ 该档 patch 数**（`countPatchesByBucket`），即 **占比条形图**，与直方图所用 bucket 计数同源。
- 仅统计 **`patchesWithCellsForTps`** 子集，与直方图一致。

### 7.2 条上标签与窄带行为

- 条带高度固定（约 **26px**），使用 **`ResizeObserver`** 读取条形容器宽度，估算每一档的像素宽度。
- **内联文案**：单档 patch 数 > 0 且估算宽度 ≥ **`INLINE_LABEL_MIN_PX`（当前约 52px）** 时，在条内显示 **`count (pct%)`** 单行（千分位 + 一位小数百分比），`tabular-nums`，过长时 **`truncate`**。
- **窄档**：不足以放下内联字时隐藏数字层；该档对应交互区保留 **`Tooltip`**，悬停显示 **分桶全称 + 同一套 compact 数字**，满足「放不下则悬停查看」。

### 7.3 图例行

- 条带下方一行 **四色方块 + 短标签**（`BUCKET_STYLES`），`title` 为完整档位描述，便于无障碍与快速辨认。

## 8. 选区 ROI 统计面板（Selection ROI Panel）

**组件**：`src/components/viewer/SelectionRoiPanel.tsx`。

### 8.1 嵌入位置与变体

- 嵌在 **TPS 分布总览**卡片内：`variant="embedded"`（默认，弱分隔）或 **`panel`**（略强的卡片边框与背景）。

### 8.2 指标定义

| 状态 | 标题副文案 | 指标来源 |
|------|------------|----------|
| 无 ROI | `Whole slide` | **`computeWsiStats(manifest)`**：全片（过滤后）patch 统计 |
| 有 ROI | `Local ROI` | ROI 矩形与 patch 求交；**Mean TPS** 为 **细胞加权**（`cellWeightedMeanTps`），与 `LocalSelectionSummary` 中细胞计数一致 |

### 8.3 展示组件（自上而下）

1. **`MetricHBar` — Mean TPS (scalar)**：0–100% 映射为条长；数值标签为格式化百分比。
2. **`MetricHBar — Patches`**：无 ROI 时显示全片 patch 数；有 ROI 时为 **`ROI patch 数 / 全片 patch 数`**，比例条表示 ROI 占全片 patch 的比例。
3. **`MetricHBar — Cells`**：同理，**`ROI cells / 全片 cells`**。
4. **`CellMixStackedBar`**：阴阳性细胞 **堆叠条**（数值来自 ROI summary 或全片 `wsiStats`）。

### 8.4 清除 ROI

- 面板右上角 **×**：**`clearLocalRoi()`**，与主视图 ROI 状态同步。

## 9. 右侧栏：选中 Patch 预览与详情

**组件**：`src/components/side/right/RightColumn.tsx`、`SelectedPatchStackedView.tsx`。

### 9.1 预览带（SelectedPatchPreviewBand）

- **`tileSizePx`**：父级传入 `预览带高度/2`，用于正方形 tile 边长。

## 10. AI 助手（浮动 + 可选内嵌）

**组件**

- **浮动**：`AiAssistantFloating.tsx` — FAB、`role="dialog"` 面板、`AiAssistantChatBody`。
- **内嵌**：`AiAssistantPanel.tsx` — 仅包裹 **`AiAssistantChatBody`**（如右栏曾用；当前主页以浮动为主）。

### 10.1 面板几何与拖拽

| 常量 | 典型值（以源码为准） | 含义 |
|------|----------------------|------|
| `PANEL_W` | 440 | 面板宽度（px），与 `style.width` 一致 |
| `PANEL_H` | 760 | 面板高度（px） |
| `max-h` | `min(85vh, 800px)` | 视口较矮时限制最大高度，防止溢出 |

- FAB 与面板均可 **拖拽**；位置 **`clamp`** 在视口内。
- 首次打开面板时相对 FAB **锚定**一侧（避免挡住按钮）。

### 10.2 Quick prompts（guided 模式）

- 文案列表：**`src/lib/agent/predefinedQuestions.ts`**，当前 **8** 条（全片概述、ROI 摘要、选中 patch、热点 patch、细胞阴阳整体、ROI vs 全片、阈值说明、分档计数表等）。
- 首次渲染前端用内置数组初始化；**挂载后 `GET /api/chat`** 若返回 `questions[]` 则 **覆盖**列表（便于服务端统一改版）。
- 点击后 **`POST /api/chat`**，`body` 含 **`mode: "guided"`**、`questionId`、`caseId`、`selectedPatchId`、`threshold`、`roiWorld`。
- **不调用大模型**；服务端 **`buildTemplateFieldsFromCase`** → **`renderGuidedAnswer`**，全文为 **Mustache 风格 `{{field}}` 填空**，语言以模板为准（当前多为英文）。
- **无需 `DEEPSEEK_API_KEY`**。

### 10.3 自由对话（chat 模式）

- 用户在输入框提交 → **`POST /api/chat`**（默认模式），body 含 **`messages`**（OpenAI 风格多轮）及 **`caseId`**、**`selectedPatchId`**、**`threshold`**、**`roiWorld`**。
- 服务端 **`getCaseStats`** → **`formatCaseStatsForPrompt`** 注入 **system** 段落；上游 **DeepSeek** 流式 SSE 返回。
- **必须配置** **`DEEPSEEK_API_KEY`**（`web-agent/.env.local`）；缺失时返回 **503** 及明确提示文案。
- 系统提示要求助手 **英文回复**（与用户语种无关）。

### 10.4 上下文一致性

- **`roiWorld`**：来自 **`localRoi?.world`**；未框选为 `null`。聊天与 guided **同源字段**，保证与 Selection ROI / 直方图一致。
- **内部唯一数值源**：**`src/lib/internal/caseStats.ts`** 的 **`getCaseStats`**（含 **全片最高 TPS patch** `wsiHighestTpsPatch` 等）；避免模型编造数字。

### 10.5 免责声明与知识库

- 模板末尾含 **非临床诊断、须执业医师确认** 等表述。
- 可选环境变量 **`PATHOLOGY_KNOWLEDGE_BASE_DIR`**；默认可能指向仓库 **`knowledge/`**。当前 **guided 路径不拼接知识库摘录**，仅为模板正文。

## 11. 数据服务与 API（Next.js Route Handlers）

根路径：`web-agent/src/app/api/`。

### 11.1 病例与资源

## 12. 全局状态与关键副作用（`src/lib/store.ts`）

### 12.1 常用字段速查

| 字段 | 含义 |
|------|------|
| `caseList` / `caseListStatus` / `caseListError` | 病例列表与加载状态 |
| `caseId` / `manifest` / `manifestStatus` / `manifestError` | 当前病例与清单 |
| `selectedPatchId` / `cells` / `cellsStatus` / `cellsError` | 选中 patch 与细胞异步加载 |
| `threshold` | 细胞阴阳阈值（默认 **0.5**），影响详情与 **`getCaseStats`** |
| `panelLayers` / `selectedLayer` | 右侧预览图层开关与当前层 |
| `previewTileSize` | 预览 tile 尺寸（夹在 **PREVIEW_TILE_MIN–MAX**） |
| `galleryBucket` / `gallerySort` / `galleryPage` | 图库筛选、排序、分页 |
| `pendingFlyToPatchId` | 图库 → 主视图飞行定位桥梁 |
| `localRoiDrawMode` / `localRoi` | ROI 绘制开关与世界矩形 + summary |
| `tpsHeatmapVisible` | KDE 热力图 |
| `osdViewer` | OSD 实例，供导航概览订阅 |
| `chatMessages` / `chatStatus` / `chatError` | 浮动助手对话 |

### 12.2 `setCase` 会重置的内容（避免跨病例串数据）

调用 **`setCase(caseId)`** 时会：

- 清空 **`manifest`**（进入 loading）、**`selectedPatchId`**、**`cells`**
- **`galleryPage` → 0**
- **`chatMessages` 清空**，**`chatStatus` → idle**（**`chatError` 未在此重置**；完全清错误态可再调 **`resetChat`**）
- **`localRoiDrawMode` → false**，**`localRoi` → null**
- **`tpsHeatmapVisible` → false**

首次 **`loadCaseList`** 成功且当前 **`caseId` 为空**时，会自动 **`setCase(data.cases[0].caseId)`** 打开第一份病例。

### 12.3 `setSelectedPatch` 与竞态

切换 patch 时先 **`cellsStatus: loading`**；请求返回后若 **`selectedPatchId`** 已变化则 **丢弃结果**，避免慢请求覆盖新选中 patch。
