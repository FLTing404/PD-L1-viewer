# TPS-Vis（web-agent）网站功能模块说明

本文档面向当前前端应用（`web-agent`，Next.js + React），按界面区域与数据链路归纳各模块职责与用户可操作行为，与实现保持对齐。技术栈要点：全切片主视图使用 OpenSeadragon 加载 DZI/金字塔；全局状态以 Zustand（`useViewerStore`）集中管理病例、清单、patch 选择、局部 ROI、TPS 热力图开关、图库分档等；部分图表为 Canvas 绘制（TPS 直方图、ROI 叠加柱等）。

**入口**：`src/app/page.tsx`。

- **顶栏**：`TopBar`，全宽固定在上方。
- **主体三列**（顶栏下方横向排列）：
  - **左栏** `LeftSidebar`：上方「标本浏览器」、下方「Patch 图库」。
  - **中栏** `LeftColumn`：上方「主阅片器」、下方「TPS 分布总览」条带（与右侧栏上下分区比例一致：约 5:2）。
  - **右栏** `RightColumn`：上方「选中 patch 预览带」、下方「选中 patch 详情」。

## 3. 标本浏览器（Specimen Explorer）

**组件**：`src/components/side/left/SpecimenExplorer.tsx`。

**功能概要**

- 从服务端扫描「分析实例」列表（病例列表），以卡片形式展示；卡片按 **平均 patch TPS（meanPatchTps）降序** 排列，便于优先浏览高表达病例。
- 每张卡片包含：缩略图（来自病例清单中的 `thumbnailRelative`）、病例 ID、平均 TPS 百分比、以及根据均值划分的简要状态文案（如 High PD-L1 / Elevated / Low expressors）。
- 点击卡片 **切换当前病例**（`setCase`），会联动加载该病例的 manifest、主视图瓦片、patch 覆盖层等。
- **Import Source Directory**：触发目录选择器（浏览器支持时）并 **刷新** 病例列表（`loadCaseList`），用于数据根目录下新增病例文件夹后重新扫描。

**状态与数据**

- 依赖 `caseList`、`caseListStatus`、`caseId`；首次进入若状态为 idle 会自动 `loadCaseList`。

## 4. Patch 图库（Patch Gallery）

**组件**：`src/components/side/left/PatchGallery.tsx`。

**功能概要**

- 以当前病例 manifest 中的 patch 为数据源，仅保留 **具备细胞级 TPS 可用数据** 的 patch（`patchesWithCellsForTps`）。
- **分档筛选**：仅显示当前 **图库分档** `galleryBucket` 与一致的 patch（与临床四档一致：Negative、TPS_1、TPS_10、TPS_50，样式见 `BUCKET_STYLES`）。
- **局部 ROI 联动**：若用户在主视图画了局部 ROI，图库可筛选为 **仅 ROI 内相交的 patch**（与 `localRoi` 世界坐标矩形求交）。
- **排序与分页**：筛选结果按 **预测 TPS 降序**；侧栏模式使用 `GALLERY_PAGE_SIZE_SIDEBAR` 分页，支持翻页；切换 ROI、分档或病例时会重置页码。
- **交互**：点击某个 patch 会 **设为选中**（`setSelectedPatch`）并 **飞行定位** 到该 patch（`flyToPatch`），与主视图与右侧详情联动。

**变体**

- `variant="sidebar"`：用于左栏下半区，布局紧凑、竖向占满。
- `variant="grid"`：若在其他场景使用则为网格分页样式（常量页大小不同）。

## 5. 主阅片器（Main Viewer）

**组件**：`src/components/viewer/MainViewer.tsx` 及其子组件。

### 5.1 OpenSeadragon 全切片视图

- 动态加载 `openseadragon`，在容器内创建 Viewer；**关闭内置导航控件与迷你导航器**，改由自定义「导航概览」组件提供。
- 使用 manifest 中的 **tileSource**（`toOsdTileSource`）加载金字塔/DZI；`crossOriginPolicy: Anonymous` 便于叠加层与缩略图跨域策略一致。
- 手势：滚轮缩放、双击缩放；**单击不放大**（避免与框选 ROI 冲突）；拖动平移。
- 视口尺寸变化时做防抖式 resize，减轻 patch 切换时的闪烁。

### 5.2 Patch 矢量覆盖层（PatchOverlay）

- 在图像坐标系下绘制各 patch 边界或标记（与 manifest 中 patch 列表对应），用于空间上下文；选中态与高亮与全局 store 同步。

### 5.3 局部 ROI：工具栏与框选（LocalRoiToolbar / LocalRoiSelector）

**组件**：`src/components/viewer/LocalRoiSelector.tsx`（工具栏与拖拽逻辑同文件导出）。

- **局部 ROI 模式**：开关 **绘制模式** 后，用户在图像上拖拽矩形；释放后依据 patch 网格 **对齐/吸附** 到 patch 边界统计（`computeLocalSelectionFromUserRect` 等）。
- ROI 存在于 **世界坐标** 矩形，store 中维护 `localRoi`；可清空、并与 **TPS 分布条、图库、SelectionRoiPanel** 联动。
- **TPS 热力图**：工具栏提供开关，控制是否在主视图上叠加 **KDE TPS 热力图**（见下）。

### 5.4 TPS 热力图叠加（TpsHeatmapOverlay）

**组件**：`src/components/viewer/TpsHeatmapOverlay.tsx`。

- 当 `tpsHeatmapVisible` 为真时，基于 manifest 调用 `buildKdeTpsHeatmapCanvas` 生成 canvas，并作为 OpenSeadragon **overlay** 铺在整张缩略图尺度对应的视口矩形上（与 `wsiMeta.thumbnailWidth/Height` 对齐）。
- 随 viewer 的 open、动画帧等刷新；关闭热力图时移除 overlay。

### 5.5 导航概览（Navigation Overview）

**组件**：`src/components/side/left/NavigationOverview.tsx`。

- 使用病例 **缩略图**（`wsiSummary.thumbnailFile`）作为底图；实时读取 OSD 中当前视口在 **图像坐标** 下的矩形，绘制 **视口框**，实现迷你地图效果。
- **点击** 缩略图上的位置会将主视图 **平移/对齐** 到对应区域（`clientToSlideUv` 等坐标转换）。
- 支持 `floating` 样式：在主视图区域内浮动（如左下角紧凑模式）；**注意**：主视图上的 KDE 热力图开关不影响此缩略图（注释说明热力图仅在大图上）。

## 6. TPS 分布总览条带（Tps Distribution Bar）

**组件**：`src/components/side/left/TpsDistributionBar.tsx`。底层统计与柱划分逻辑见 **`src/lib/tpsHistogram.ts`**。

**功能概要**

- 占据中栏 **下方约 2/7 高度**（与右侧详情区比例一致），整体是一张 **卡片式仪表盘**。
- **全切片 TPS 直方图（自适应分辨率 + 等像素柱宽）**：
  - 内部仍以 **0.1% TPS** 细粒度分箱（`TPS_HISTOGRAM_BIN_COUNT`，即 `buildTpsPercentBins`）累计 patch 计数；
  - **绘制**时按 **`buildEqualPixelHistogramPlan`** 将 plot 宽度划分为若干柱，每柱 **CSS 像素宽度恒定**（\(W_{\mathrm{bar}}=\mathrm{plotW}/N\)，\(N\) 由最小柱宽约 **4px**（`HISTOGRAM_MIN_BAR_PX`）、上限约 480 柱约束）；
  - 各柱对应的 **TPS 区间宽度（精度）** 由该档的 **可视带宽**（`bandWidths`，来自「patch 数占比」的比例尺）单独决定：屏幕等像素采样后用比例尺逆映射得到 `tpsEdges`，最后用 **`aggregateFineBinsByTpsEdges`** 把细 bin 按重叠比例并入各柱；
  - **柱与背景带共享同一套 \(x\) 映射**（`blendTpsAxes` / `createProportionalTpsAxis`），保证某档背景颜色内的柱总质量精确等于该档 patch 数（与 TPS Allocation Band 比例一致）；
- **Y 轴刻度**：纵轴为 patch **计数**；**全片模式**下最高柱约占图高的 **90%**（`WS_FILL_RATIO`）；**ROI 内有 patch** 时改为展示 ROI 分布柱，最高柱约 **80%**（`ROI_FILL_RATIO`），配色见 `ROI_FILL` / `ROI_STROKE`。
- **ROI 与全片切换**：无 ROI 或 ROI 内无 patch 时绘制 **全片** 柱；ROI 内有 patch 时 **仅绘制 ROI 内** patch 的分布柱（同一卡片内对比逻辑由状态切换体现，不再与全片柱双层叠加）。
- **分档占比带**：展示 Negative / TPS_1 / TPS_10 / TPS_50 四档在（过滤后的）patch 集合中的比例 **条带**（`BAND_BUCKETS`）。
- **与图库联动**：点击某一档位或图例时，可 **设置 `galleryBucket`**，从而驱动左侧 Patch Gallery 只显示该档 patch。
- **SelectionRoiPanel**：嵌入展示当前选区或全片的 **细胞加权平均 TPS、阴阳性细胞、patch 数量、相对全片占比** 等（见下节）。
- **HilbertSpatialStrip**：在同一总览区域内展示 **全片四档混合条**（见第 7 节）。

**布局**

- 使用 `ResizeObserver` 等多源宽度读取，避免 flex 布局延迟导致的画布宽度为 0，保证图表随窗口缩放正确。

### 6.1 计算方法与符号（论文表述取向）

以下记号与公式与实现 **`tpsHistogram.ts`**、**`TpsDistributionBar.tsx`** 对齐，表述风格便于向 ChinaVis、IEEE *TVCG* 类稿件的「方法（Methods）」小节迁移（符号定义 → 目标函数/映射 → 离散化与聚合）。

#### 6.1.1 基本记号

| 符号 | 含义 |
|------|------|
| \(\tau\) | 模型输出的 patch 级 TPS，\(\tau\in[0,1]\)（与代码 `patchPredTps` 一致） |
| \(p\) | TPS 百分比，\(p=100\tau\) |
| \(\mathcal{P}\) | 参与统计的 patch 集合（含细胞级 TPS 的过滤子集） |
| \(W_{\mathrm{plot}}\) | 绘图区水平像素宽度（`PLOT_W`） |
| \(x_0\) | 绘图区左边界横坐标（`PX0`） |

#### 6.1.2 细粒度直方图（数据层，固定 0.1% 分辨率）

将每个 patch 归入离散索引 \(k\in\{0,\ldots,K\}\)，\(K=1000\)：

\[
k \;=\; \mathrm{clamp}\bigl(\mathrm{round}(1000\,\tau),\,0,\,1000\bigr).
\]

第 \(k\) 个细 bin 对应的标称 TPS 百分比区间为半开区间（与聚合实现一致）

\[
I_k \;=\; \bigl[10k/K,\;10(k+1)/K\bigr) \;=\; \bigl[k/10,\,(k+1)/10\bigr) \quad (\%).
\]

区间宽度 \(\Delta p_{\mathrm{fine}} = 0.1\%\)。令 \(c_k\) 为落入该索引的 patch 个数（`buildTpsPercentBins`），则 \(\sum_k c_k = |\mathcal{P}|\)。

#### 6.1.3 比例尺横轴（可视带宽，背景带与刻度）

临床四档 \(b\in\{\mathrm{Neg},\mathrm{T1},\mathrm{T10},\mathrm{T50}\}\) 对应 TPS 分段边界 \(0,1,10,50,100\)（%）。记档内 patch 数为 \(n_b\)，\(N_{\mathrm{tot}}=\sum_b n_b\)。各档在横轴上分配的像素宽度为

\[
W_b \;=\;
\begin{cases}
\dfrac{n_b}{N_{\mathrm{tot}}}\,W_{\mathrm{plot}}, & N_{\mathrm{tot}}>0,\\[6pt]
\dfrac{1}{4}W_{\mathrm{plot}}, & N_{\mathrm{tot}}=0\ \text{（均匀退化）}.
\end{cases}
\]

比例映射 \(f_{\mathrm{prop}}:[0,100]\to[x_0,x_0+W_{\mathrm{plot}}]\) 为分段线性（档内 \(p\) 均匀拉伸到该档像素宽度），即代码 `createProportionalTpsAxis` 中的 `mapTpsToX`。界面动画时在两种轴实例间线性混合：

\[
f_{\mathrm{blend}} \;=\; (1-\lambda)\,f^{(1)} \,+\, \lambda\, f^{(2)},\qquad
W_b^{\mathrm{blend}} \;=\; (1-\lambda)\,W_b^{(1)} \,+\, \lambda\, W_b^{(2)},
\]

其中 \(\lambda\in[0,1]\) 为插值系数（`blendTpsAxes`）。**直方图柱宽与位置** 同样基于该比例尺：在屏幕 \(x\) 轴上等像素分割，柱边界由 \(f_{\mathrm{blend}}^{-1}\) 给出（见 6.1.4），保证柱与背景临床带 **逐像素对齐**。

#### 6.1.4 等像素柱与可视带宽驱动的自适应精度（核心）

为消除「柱 \(x\) 映射与背景带 \(x\) 映射不一致」的视觉错位（早期版本曾以 \(\sigma_b\cdot W_b\) 加权累积构造柱边界，会让一部分高档柱被画在低档背景内），最终方案是：**柱的 \(x\) 划分与比例尺背景带完全共享一套映射**，由「可视带宽」单方面决定每柱代表的 TPS 精度（敏感度权重不再独立施加于 \(x\) 上）。

**柱数与等像素柱宽**：

\[
N_{\mathrm{bar}} \;=\; \mathrm{clamp}\Bigl(\Bigl\lfloor \frac{W_{\mathrm{plot}}}{w_{\min}} \Bigr\rfloor,\,1,\,N_{\max}\Bigr),
\qquad
W_{\mathrm{bar}} \;=\; \frac{W_{\mathrm{plot}}}{N_{\mathrm{bar}}}.
\]

默认 \(w_{\min}=4\)（CSS px，可调）、\(N_{\max}=480\)（`buildEqualPixelHistogramPlan`）。

**柱 TPS 边界**：屏幕等像素采样后由比例尺逆映射回 TPS 百分比：

\[
x_i \;=\; x_0 + i\, W_{\mathrm{bar}},\qquad
e_i \;=\; f_{\mathrm{blend}}^{-1}(x_i),\qquad i=0,\ldots,N_{\mathrm{bar}}.
\]

由此第 \(i\) 根柱覆盖 \(p\in[e_i,e_{i+1})\)，**柱与档背景带的边界对齐**：落在 \(b\) 档背景上的所有柱集合 \(B_b\) 满足

\[
\bigcup_{i\in B_b}[e_i,e_{i+1}) \;=\; [p_b^{\mathrm{lo}},\,p_b^{\mathrm{hi}}).
\]

**每柱 TPS 精度（自适应于该档的可视带宽）**：在档 \(b\) 内，柱数 \(K_b = W_b / W_{\mathrm{bar}}\)，故

\[
\Delta p_i \;=\; e_{i+1}-e_i \;=\; \frac{p_b^{\mathrm{hi}}-p_b^{\mathrm{lo}}}{K_b}
\;=\; \frac{p_b^{\mathrm{hi}}-p_b^{\mathrm{lo}}}{W_b}\, W_{\mathrm{bar}}
\quad (\,i\in B_b\,).
\]

即「档内 patch 多 ⇒ 可视带宽 \(W_b\) 大 ⇒ 该档 TPS 精度 \(\Delta p_i\) 细」，与 \(\sigma_b\) 解耦。\(\sigma_b\) 若仍需引入（如未来用户偏好），可作用于 \(W_b\)（重定义档宽度）而非 \(x\) 映射，从而保留对齐性。

#### 6.1.5 细 bin 到柱上的质量守恒聚合

对第 \(i\) 根柱，区间 \([e_i,e_{i+1})\) 与细 bin 区间 \(I_k\) 求交，按比例分配计数（长度与 \(\Delta p_{\mathrm{fine}}=0.1\) 归一）：

\[
\tilde{c}_i \;=\; \sum_{k=0}^{K} c_k \cdot
\frac{\mathrm{length}\bigl(I_k \cap [e_i,e_{i+1})\bigr)}{\Delta p_{\mathrm{fine}}}.
\]

即 `aggregateFineBinsByTpsEdges`；当柱边界与细 bin 对齐时退化为整数求和，否则为重叠比例加权。该聚合保证 **质量守恒**：\(\sum_i \tilde{c}_i = \sum_k c_k = |\mathcal{P}|\)，于是 **档 \(b\) 内柱面积之和**

\[
\sum_{i\in B_b}\tilde{c}_i \;=\; n_b,
\]

即每个临床带（背景颜色区）内 **直方图柱的总质量恰好等于该档 patch 数**，与第 7 节占比条带的数字一致。

#### 6.1.6 纵轴尺度与柱高（顶边留白）

记 \(H_{\mathrm{plot}}\) 为绘图区高度，\(\tilde{c}_{\max}=\max_i \tilde{c}_i\)（全片或 ROI 各自的聚合序列）。为使 **最高柱不占满整幅高度**，引入填充比 \(\rho\in(0,1]\)，纵轴显示上界取

\[
Y_{\max} \;=\; \frac{\tilde{c}_{\max}}{\rho}.
\]

柱 \(i\) 的绘制高度（像素）为

\[
h_i \;=\; \min\!\left(H_{\mathrm{plot}},\;\frac{\tilde{c}_i}{Y_{\max}}\,H_{\mathrm{plot}}\right).
\]

实现中：**全片** \(\rho=\rho_{\mathrm{ws}}=0.9\)（`WS_FILL_RATIO`）；**ROI 模式** \(\rho=\rho_{\mathrm{roi}}=0.8\)（`ROI_FILL_RATIO`）。该写法与 TVCG 类文中常见的「normalized display range」表述一致：通过 \(\rho\) 留出顶部裕量，避免单 bin 贴顶造成饱和感。

#### 6.1.7 混合条（与直方图一致的档位占比）

第 7 节 Hilbert 条带各档水平宽度 \(\omega_b\) 满足 \(\omega_b \propto n_b\)，\(\sum_b \omega_b = W_{\mathrm{plot}}\)，即 **占比条形图** 的标准编码；与本节 \(W_b\) 同源计数但用途为 **类别混合可视化**，非 TPS 连续轴。

## 8. 选区 ROI 统计面板（Selection ROI Panel）

**组件**：`src/components/viewer/SelectionRoiPanel.tsx`。

- 嵌入在 TPS 分布总览中（`variant="embedded"` 或 `"panel"`）。
- **无 ROI**：展示 **Whole slide** 维度统计（来自 `computeWsiStats`）：patch 数、细胞数、mean TPS 等。

## 9. 右侧栏：选中 Patch 预览与详情

**组件**：`src/components/side/right/RightColumn.tsx`、`SelectedPatchStackedView.tsx`。

### 9.1 布局

- 右侧宽度由 **预览带高度** 动态决定：预览区高度的一半作为方形 tile 边长，使预览拼图与栏宽对齐（`ResizeObserver` 测量 `previewBandRef`）。
- 上 **5** 下 **2** 的 flex 比例：上与主视图区对齐，下与 TPS 分布条对齐。

### 9.2 预览带（SelectedPatchPreviewBand）

- 展示当前选中 patch 的 **多层预览小图**（如原图、叠加层等，由 `PanelLayer` 与 store 中的图层状态驱动），支持 **局部缩放与平移**（内置 `MIN_ZOOM`/`MAX_ZOOM` 与 pan 夹紧）。
- 切换病例或选中 patch 时通过 `key` 重置内部状态，避免旧图残留。

### 9.3 详情卡片（SelectedPatchDetailCard / PatchCellStatsInline）

- 展示选中 patch 的 **预测档位、badge 样式、预测 TPS 百分比**。
- **细胞级结果**：异步加载该 patch 的 cells（见 API），展示 **阴阳性细胞计数、比例条、与全片细胞基数对比**；阈值 `threshold` 参与 `computeCellStats`。
- 加载中显示 Skeleton；失败时显示错误文案。
- 包含 patch 在切片上的 **位置文案**（`formatPatchOriginXY`）及预览图 URL 解析（`patchPreviewFileUrlFromEntry`）等。

## 10. AI 助手（浮动）

**组件**：`src/components/side/right/AiAssistantFloating.tsx`、`AiAssistantPanel.tsx`（内嵌 `AiAssistantChatBody`）。

**交互**

- 右下角 **FAB** 打开/关闭面板；面板与按钮均可 **拖拽**，位置限制在视口内。
- **Quick prompts**：三条预置英文快捷问题（文案见 `src/lib/agent/predefinedQuestions.ts`），点击后调用 **`POST /api/chat`**，**`mode: "guided"`**，仅做 **模板填空**，答案英文；数值全部来自服务端 **`getCaseStats`**（见第 11 节内部统计），**不调用大模型**，也不需要 DeepSeek Key。
- **自由输入**：走 **`POST /api/chat`** 默认模式（不传 `mode` 或 `mode: "chat"`），服务端使用 **DeepSeek** 流式返回（需环境变量 **`DEEPSEEK_API_KEY`**，配置于 `web-agent/.env.local`）。系统提示词要求 **英文回复**；病例上下文由 **`formatCaseStatsForPrompt`** 注入，与 guided 同源。
- **随请求上传的上下文字段**（由 `AiAssistantChatBody` 组装）：`caseId`、`selectedPatchId`、`threshold`、`roiWorld`（来自 store 的 **`localRoi.world`**，即当前矩形选区；未框选则为空）。自由对话与 guided 共用这些字段，保证 ROI / 选中 patch 与界面一致。

**内部统计与问答边界**

- 全片指标、ROI 汇总、选中 patch 细胞级统计、以及 **「全片 TPS 最高的 patch」**（`patch_id` + WSI 坐标 + 档位）均由 **`src/lib/internal/caseStats.ts`** 中 **`getCaseStats`** 一次性算出；注入 LLM 的文本与 guided 模板字段均基于此快照，避免模型「编造」数值。
- 预置模板末尾包含简短免责声明：**非临床诊断，须执业医师确认**；不对数值本身做「AI 推断不可靠」类表述——数字视为本系统管线输出。
- **知识库目录**（可选）：默认 **`PATHOLOGY_KNOWLEDGE_BASE_DIR`** 未设置时使用仓库根下 **`knowledge/`**（相对 `web-agent` 为 `../knowledge`），可放置 PDF / Markdown / TXT 供后续扩展；当前 guided 回答 **不再拼接知识库摘录**，仅模板正文。

## 11. 数据服务与 API（Next.js Route Handlers）

路径均在 `src/app/api/` 下。

### 11.1 病例与资源

| 路由 | 作用 |
|------|------|
| `GET /api/cases` | 列出数据根下可用病例及清单所需元信息（供 Specimen Explorer）。 |
| `GET /api/cases/[caseId]/manifest` | 返回该病例 **CaseManifest**（瓦片源、patch 列表、wsi 元数据等）。 |
| `GET /api/cases/[caseId]/file/[...path]` | 按相对路径提供病例目录下的静态文件（DZI 瓦片、缩略图、patch 裁剪图等）。 |
| `GET /api/cases/[caseId]/patches/[patchId]/cells` | 返回指定 patch 的 **细胞级** 预测结果（供右侧详情统计）。 |

前端通过 `caseFileRelativeUrl`、`patchPreviewFileUrlFromEntry` 等工具函数拼接上述 file API 的 URL。

### 11.2 内部统计（执行层，推荐唯一数据源）

| 路由 | 作用 |
|------|------|
| `POST /api/internal/case-stats` | Body：`caseId`、可选 `threshold`、`selectedPatchId`、`roiWorld`；返回 **`CaseStatsSnapshot` JSON**（与 `getCaseStats` 一致）。可选 `includePromptText: true` 附带面向 LLM 的 **`promptText`**（与聊天注入同源）。Agent / 编排层应通过此接口或直接在服务端 `import { getCaseStats }`，避免重复解析 manifest/cells。 |

核心实现：**`src/lib/internal/caseStats.ts`** 中 **`getCaseStats`**；快照中含 **`wsiHighestTpsPatch`**（在「含细胞数据的 patch」集合上 **`patchPredTps` 最大** 的那一条，用于回答「哪一块 TPS 最高」类等）。

### 11.3 AI 对话

| 路由 | 作用 |
|------|------|
| `GET /api/chat` | 返回预置问题列表 `{ questions: [{ id, label }] }`（与前端初始列表一致，便于日后服务端驱动）。 |
| `POST /api/chat` | **`mode: "guided"`**：需 `questionId`、`caseId` 等，返回 JSON **`{ mode, questionId, content }`**，内容为英文模板填空。**默认（流式）**：请求体含 OpenAI 风格 **`messages`**，转发 DeepSeek Chat Completions **SSE**；请求体中的 **`roiWorld`** 参与 **`getCaseStats`**，注入系统提示中的病例段落。 |

## 12. 全局状态与关键概念（便于对照代码）

**Store**：`src/lib/store.ts`（以实际导出为准）。

- **caseId / manifest**：当前病例与完整清单；manifest 驱动 OSD、patch 列表、热力图、直方图等。
- **selectedPatchId / flyToPatch**：选中 patch 与主视图相机动画。
- **galleryBucket / galleryPage**：图库分档与分页。
- **localRoi / localRoiDrawMode**：局部 ROI 几何与是否处于绘制模式。
- **tpsHeatmapVisible**：TPS KDE 热力图开关。
- **osdViewer**：主 OSD 实例引用，供 NavigationOverview 等订阅视口。
- **cells / cellsStatus**：当前选中 patch 的细胞列表加载状态。
- **threshold**：细胞阴阳判定阈值，影响详情区统计与 **`getCaseStats`** / 聊天上下文。
- **chatMessages / chatStatus / chatError**：AI 浮动助手对话列表与流式状态。
- **appendChatMessage / updateAssistantMessage / resetChat / setChatStatus**：对话生命周期。

## 13. 小结

| 模块 | 用户价值 |
|------|----------|
| 顶栏 | 应用标识与主题说明 |
| 标本浏览器 | 选病例、扫目录、按均值浏览 |
| Patch 图库 | 按档位与 ROI 浏览 patch、点击跳转主视图 |
| 主阅片器 | 金字塔阅片、patch 覆盖、ROI 框选、TPS 热力图 |
| 导航概览 | 缩略图上视口定位与快速跳转 |
| TPS 分布总览 + Hilbert 条 + ROI 面板 | 等像素柱直方图（敏感度×带宽精度）、全片约 90% / ROI 约 80% 柱顶留白、档位占比、图库分档联动 |
| 右侧栏 | 选中 patch 的多层预览与细胞级指标 |
| AI 浮动助手 | Quick prompts（模板 + `getCaseStats`）与 DeepSeek 自由对话（需 Key）；上下文含 ROI / 选中 patch |
| API | 病例清单、manifest、静态文件、细胞结果；**`/api/internal/case-stats`**、**`/api/chat`**（GET 预置问题 / POST guided 或 SSE） |
