# 演示案例文稿（与 TPS-Vis 实现对齐）

下文模仿 IEEE TVCG 类系统论文中「应用场景 / 任务驱动评估」的常见写法：**先交代数据形态与任务痛点，再描述交互流程与界面组件如何支撑分析**。本文稿对应路径型演示脚本，**不涉及外部病理专家参与或盲法评审**；结论性表述限于算法输出与可视化推理链条，临床决策仍以院内流程为准。

---

## 案例一：同片远距离对照样本的交互锚定与比对效率

### 1.1 动机与数据特征

常规制片质控中，常将患者穿刺组织与远端对照（例如淋巴结等对照组织）置于同一载玻片，以获得染色与切片层面的可比性。此类排版往往在整张全切片图像（WSI）上形成**空间高度离散**的布局：大片空白背景分隔多个生物学兴趣区域。经典单视口阅片在这种布局下需要用户在患者区域与对照区域之间进行**长距离平移**，易产生视觉搜索负荷与空间参照减弱等问题（文献中常归纳为 navigation / orientation 成本）。

本案例选取一例具有典型「一侧为患者、一侧为对照」空间排版的 WSI，用于展示 **TPS-Vis** 在多焦点、大留白场景下，如何通过**多尺度导航 + 局部 ROI 统计 + Patch 级检索**支撑对照阅读任务。

### 1.2 系统侧的数据准备（与实现对齐）

病例载入后，前端基于清单（manifest）解析金字塔瓦片源；Patch 网格由离线管线导出为固定尺度（如 **512×512**）片段，并附带 patch 级预测 TPS 及细胞级导出字段。主视图（OpenSeadragon）负责宏观导航；Patch 覆盖层提供空间锚点；仅保留具备可用细胞级信息的 patch 参与 TPS 分布与图库列表（与 `patchesWithCellsForTps` 一致）。

### 1.3 推荐交互流程（演示脚本）

1. **病例入口**：在标本浏览器（Specimen Explorer）中选择目标病例；卡片可按摘要指标排序，便于优先打开感兴趣样本。
2. **宏观定位**：利用导航概览（Navigation Overview）在缩略图上点击或拖拽视口框，将主视图快速对齐至**患者侧**组织岛；必要时叠加 Patch 边界以确认网格对齐。
3. **局部 ROI**：开启局部 ROI 工具，在患者组织区域拖拽矩形；系统在 patch 网格上对齐选区，驱动 **Selection ROI 面板** 展示该矩形内的 patch 槽位数、细胞加权平均 TPS、阴阳性细胞计数及分档 bucket 分布。
4. **细粒度对照**：在 Patch 图库中按档位筛选或按 TPS 排序，单击 patch **飞行定位**至主视图；右栏展示当前 patch 预览与详情。
5. **对照侧跳转**：通过导航概览将视口移动至**对照侧**，重复 ROI / 图库 / 直方图路径；由此在同一交互框架下完成双侧读片，而无需依赖额外的「专家标注图层」。
6. **可选文本汇总**：浮动 Pathology Insight 助手支持基于当前病例统计字段的 **guided 问答**（来自内部 `getCaseStats` 的快照），用于生成结构化摘要；**该输出为管线数值复述，不构成独立病理结论**。

### 1.4 案例一侧重验证点（表述边界）

本案例强调：**大留白 WSI 下的跨焦点导航效率**与** ROI–Patch–直方图链路的一致性**（同一套比例尺与 bucket 定义贯穿总览条带与柱图）。不对阅片时间或诊断准确率做宣称；若撰写论文，可将此类案例定位为 **qualitative scenario illustration** 而非临床 RCT。

## 案例二：局部高表达干扰下的异质性与边界判读辅助

### 2.1 动机与数据特征

PD-L1 表达在空间上常呈**异质性**：同一活检条带内可同时存在低表达与高表达灶。若整条穿刺在幻灯片上被网格切分为多个 patch 集合，则**全局聚合指标**（例如条带级平均 TPS）可能掩盖局部极端区域；此时分析任务从「读一个数」转为「解释分布形状与空间来源」。

本案例构造一类典型干扰：**左侧为患者穿刺、右侧为对照**；患者侧组织沿扫描方向过长，被网格划分为**两块相邻 patch 区域**。观测层面可出现：**总体条带级 TPS 居中**，但其中一块局部显著偏高、另一块偏低（演示中可出现例如总体约 **35.7%**，而两块分别约 **61.2%** 与 **13.9%** 的对比——具体数值以载入清单为准）。

### 2.2 系统支持的推理路径

1. **全局视图**：TPS 分布总览（`TpsDistributionBar`）在全片模式下给出 **0.1% 细粒度 bin 聚合后经比例尺映射的直方图**，并与临床四档背景带对齐；全片 **TPS Allocation Band**（档位占比条）给出「Negative / TPS_1 / TPS_10 / TPS_50」混合比例。
2. **异常形态提示**：当用户在穿刺组织上框选 **整块穿刺 ROI** 时，若异质性较强，直方图可出现**双峰或多峰**结构（例如在约 **1%** 附近与 **50%–100%** 区间各形成一个峰）。该现象**提示**「均值不足以代表局部」，引导用户转向空间拆解。
3. **空间拆解**：分别框选两个子区域（或与 patch 网格对齐的两个 ROI），对比两侧 **ROI 内直方图**、**细胞加权平均 TPS** 及 **Selection ROI 面板**中的 bucket 计数；Patch 图库可限定为 ROI 内 patch，排序浏览高 TPS patch。
4. **对照参照**：右侧对照组织可作为「低表达参照语境」，在同一交互范式下浏览，强化对患者侧局部高峰的解释链条（仍为**数据驱动的视觉比对**，非诊断断言）。

### 2.3 案例二侧重验证点（表述边界）

本案例强调：**均值聚合 vs 分布形态 vs 局部 ROI** 三者联动，用于说明系统在 **heterogeneity-aware exploration** 上的交互设计；双峰直方图作为**可视化线索**，需与院内判读流程区分。**本文稿不包含病理专家对病例的最终裁定或金标准标签。**
