# 案例二：干扰易感带、临界分档与 Patch 级复核溯源（与当前实现对齐）

本合并文档由原「案例二（易干扰与边界）」与「案例三（临界分档与分布溯源）」整合而成：二者在同一套交互中衔接——**先借分布与空间视图觉察异常或难读区，再用画廊与细读落到具体 Patch**。

---

## 对应痛点与临床背景

### （1）负荷与一致性

全切片图像（WSI）尺度极大，肿瘤微环境异质性高，染色强度存在批内/片内波动；传统依赖病理专家肉眼的**半定量评估**不仅工作负荷极高，还存在显著的**观察者间差异（inter-observer variability）**。

### （2）IASLC 所述干扰

IASLC 等临床指南强调：**坏死组织、肺泡巨噬细胞等免疫细胞**的阳性表达或强染色，易对**有效肿瘤细胞 PD-L1/TPS** 的判读造成干扰。上述情形常集中于**组织边缘、坏死交界、炎症浸润带**等「难读」区域，常规巡片易**浏览不充分**或**被整体均值掩盖**，需在 **Patch 粒度**上完成**定位与复核**。

### （3）临界档与分布形态

PD-L1 TPS 在报告中常与 **1%、10%、50%** 等阈值相关；同一 WSI 内既可**弥漫弱阳性**，也可**少数极高表达灶**，肉眼难以稳定判断**整体究竟落在哪一档、是否被局部极端或交界区主导**。仅报告**单一均值**易掩盖**多峰、长尾、各档 Patch 占比不均** 等信息。

**本案例聚焦**：在 **「干扰 + 临界/形态可疑」** 交织时，如何用系统完成 **「统计觉察 → 空间索引 → 画廊锁定 → Patch 细读（及可选 ROI 对照）」**，不替代病理诊断，而提供**可定位、可比对、可追溯**的证据链。

---

## 对应设计目标

| 叙事重点 | 与本系统「设计目标」对应 |
|----------|---------------------------|
| 大尺度不遗漏难读微区；分布尾部与成簇 | **G1** 漫游 + **NavigationOverview**；**G3** 直方图 / **Hilbert** |
| 临界档、桶占比、全片 vs ROI | **G2** / **G3**：**TPS Distribution Overview** 全片/ROI；**Selection ROI** 细胞加权 Mean TPS；**线性 0–100% 横轴**（`createLinearTpsAxis`） |
| 降低主观差异、可复核证据 | **G5** **cell_class** / 概率图层、可调 **`threshold`**；**patchPredTps** / **patchPredBucket** |
| 定位可疑 Patch、溯源 | **G4** **Patch 画廊**（按桶、按 TPS 排序）↔ **主视图 Patch 网格**；fly-to 选中 |

## 1. 作图设计（Suggested Visuals）

### 图 A（问题语境示意）

左半可强调 **IASLC 相关干扰**（坏死、巨噬细胞、淡染交界）；右半可强调 **临界/灶性** 与 **分布形态**（示意双峰或长尾，非具体病例像素）。**无需**与真实 WSI 逐像素一致。

### 图 B（TPS Distribution Overview：分布 + 分档底色 + Hilbert）

**同一中列下方面板**内并置：

- **直方图**：**101 个 1% 分箱**，**线性 0–100%** 横轴；全片为柱状频数（无平滑曲线）；可标注主峰、**拖尾 / 肩峰** 以支持「形态可疑 / 临界」叙事。  
- **临床档弱色带**：横轴按 **TPS% 线性刻度**，四档区间宽度对应固定临床跨度（非按桶 Patch 数比例拉伸）；各档 **patch 占比** 仍由直方图形状与右栏标量阅读。  
- **Spatial Hilbert Trace**：**predTPS** 序贯色带（静态概览），辅助判断高表达**是否成段**；正文需说明 Hilbert 为**数学序贯**而非解剖走向。

有 **ROI** 时切换为 ROI 子分布，与 **Selection ROI** 仪表盘（细胞加权 Mean TPS 等）**同一视线**对照。

### 图 C（Patch 级空间索引：网格 + 画廊）

- **主视图 Patch 网格**：**`patchPredBucket`** 着色，与画廊 **BUCKET_STYLES** 一致。  
- **Patch 画廊**：按 **TPS 升/降序**、按 **分级桶** 筛选；优先展示 **TPS_1 / TPS_10** 或与叙事相关的桶，用于「干扰易感带 / 弱阳性 / 高灶」定点。

仅 **`numCells > 0`** 的 Patch 参与热力图、直方图等聚合（`patchesWithCellsForTps`）。

### 图 D（画廊 → 飞抵 → Selected Patch 细读）

点击画廊条目 → **`selectedPatchId`** → 主视图 **视口跳转**；右侧 **双格预览**（**cell_class**、**heatmap_overlay** / **center_prob**）与指标卡（**预测桶、Patch pred TPS、阴阳性计数**，`computeCellStats` + **`threshold`**）。

**叙事**：**干扰区 / 临界区** 的最终判断仍依赖 **人在 Patch 内** 结合形态与概率；**`patchPredTps`** 来自离线清单，与逐细胞阈值统计**未必数值一致**（见 `系统布局与模块说明.md`）。

### 图 E（可选：顺序 ROI 与全片对照）

**两次会话截图并列**：无 ROI 时全片直方图 + Selection ROI（全片指标）；划定 **可疑灶 ROI** 后再截，对比 **ROI 内 Mean TPS** 与 **直方图 ROI 模式**。实现上为 **单一 ROI 状态机**，非双 ROI 同时激活（同案例一脚注）。

## 2. 案例解释（Explanation）— 正文草案

WSI 尺度与指南所述 **坏死、巨噬细胞等干扰** 叠加 **染色波动**，使 PD-L1 判读同时面临 **遗漏难读带**、**观察者间差异** 与 **临界档 / 分布形态** 的多重挑战：单纯依赖肉眼半定量或单一均值，难以同时回答 **「有效肿瘤区表达负担」** 与 **「是否被无关阳性或灶性极端主导」**。

本系统通过 **底部 TPS 概览** 并联 **细粒度直方图（线性横轴）、临床档底色带、Hilbert 序贯、Selection ROI**，在**同一交互框架**内完成 **统计警觉（分布与各档占比）** 与 **空间觉察（网格 / 序贯）**；再经 **画廊排序与分桶** 将注意力导向 **候选 Patch**，在右侧以 **细胞级图层与可调阈值** 完成 **证据闭环**。由此，**案例二（合并）** 与 **案例一（离散组织 + KDE + 顺序 ROI）** 分工明确：**案例一侧重宏观抵达与 ROI 量化**；**案例二侧重干扰与临界情境下的 Patch 级溯源与复核**。

可选 **LLM 浮动助理** 用于归纳与对话，**不改变**底层推理结果。
