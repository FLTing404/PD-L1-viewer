# 案例一：远距离离散组织的全局快速定位与局部独立量化（与当前实现对齐）

## 对应痛点

切片中组织离散且空白区域极大，人工拖拽寻片耗时；不同组织块之间可能存在表达异质性，需要分别评估。

## 对应设计目标（与系统 §4.1 / TVCG 式叙述可对齐）

| 文中原表述 | 与本系统「设计目标」对应关系 |
|------------|------------------------------|
| DG2（多尺度可视化） | **G1** 千兆像素导航与空间上下文；**G3** 分布与 Hilbert 序贯对照 |
| DG3（自动量化分析） | **G2** ROI 与全片统计同一通道；清单侧 **patchPredTps / numCells** 聚合 |
| DG4（高效交互探索） | **G4** 画廊 ↔ 主视图联动；**G5** Patch 细读与可选 LLM |

## 1. 作图设计（Suggested Visuals）— 按代码可实现的画面改写法

### 图 A（原始全切片宏观视图）

展示一张具有代表性的 WSI：**绝大部分为扫描空白**，仅在例如对角两侧出现两块面积较小、相距较远的组织区。实现上，主视图使用 **OpenSeadragon 多分辨率瓦片**；病例加载后缩略比例由清单中 **`wsiMeta.thumbnailWidth/Height` 与 `thumbScaleX/Y`** 与全片像素对齐。

### 图 B（全局热力图导航视图）— **实现细节补充 / 与「等值线」表述的差异**

当前前端 **并非** 绘制 KDE **等值线（isocontours）**，而是在 **与缩略图同尺寸的矩形区域** 内叠加一张 **二维加权核密度热力图**（`buildKdeTpsHeatmapCanvas`，由 **`TpsHeatmapOverlay`** 挂到 OSD 视口上，`mixBlendMode: multiply`）。

- **核**：对每个 **`numCells > 0`** 的 Patch（`patchesWithCellsForTps`），取其中心在**缩略图坐标**下的投影 \((c_x, c_y)\)，高斯核带宽 \(\sigma\) 随缩略图尺寸与 Patch 数量自适应（系数约 **0.18/√n** 量级并夹紧），**权重为 `patchPredTps`**（连续 0–1，非仅 0/1）。
- **颜色**：密度场归一化后经 **冷–暖连续色带** 映射为 RGBA（`coolWarmRgba`），再放大绘制到显示画布；**广袤空白**对应无 Patch 或极低权重区域，视觉上接近无信号；远端组织团块因 Patch 密度与 TPS 权重形成 **热点（hotspot）**。
- **开关**：由主视图工具栏控制全局布尔 **`tpsHeatmapVisible`**，避免全程遮挡组织纹理。

**可作图说明**：将示意图标注为「**基于 Patch 中心加权 KDE 的全局 TPS 热力图（非等值线）**」。若论文插图希望保留「等值线」隐喻，可在 caption 中写明「等值线为示意；系统实现为栅格化 KDE 叠加」。

**辅助导航**：主视图一角可叠 **`NavigationOverview`**（缩略图上视口框 + 点击跳转），与热力图正交，用于 **Pan/Zoom 定向**，减轻离散组织寻路成本。

### 图 C（双 ROI 框选与独立 TPS 量化视图）— **与当前交互模型的差异及推荐画法**

**代码事实**：全局状态 **`localRoi` 仅为单个矩形 ROI**（`setLocalRoi` / `clearLocalRoi`）；ROI 边界经 **`computeLocalSelectionFromUserRect`** **吸附到 `wsiMeta.patchSize` 网格**（数据管线常见 **512×512**，以清单为准）。

因此 **不能** 在同一界面时刻展示「两个同时生效的 ROI-1 / ROI-2 及其并排独立面板」。推荐作图与叙述调整为下列**等价临床 story**：

1. **顺序对比（与实现一致）**：医生先框 **ROI-1** → 中列下部 **TPS Distribution Overview** 进入 ROI 统计模式，直方图展示 ROI 内分布；**右侧 Selection ROI 仪表盘**展示该 ROI 的 **Mean TPS（细胞加权）**、Patches/Cells 相对全片、Cell mix 等 → **清除 ROI** → 再框 **ROI-2**，重复读取同一套面板，从而在叙事上完成 **「两块离散组织的独立量化对比」**（时间上分两步，而非几何上双框并存）。
2. **对比的可视化呈现**：插图画成两个 **时间片** 或 **左右两栏「截图对比」**（左：ROI-1 激活时的界面；右：ROI-2 激活时的界面），标注「当前实现为单一 ROI 状态机」。

**细胞红/绿标点**：全片主视图 **Patch 网格**按 **`patchPredBucket` 着色**；**单细胞级红/绿（阴阳性）** 出现在 **右侧 Selected Patch 预览带** 的 **`cell_class`** 等图层（加载该 Patch 的 `cells.csv` 后，按全局 **`threshold`（默认 0.5）** 对 `cellPosProb` 二值化展示）。叙述宜写为「在选中 Patch 尺度复核细胞标签」，而非「ROI 内每一像素同时铺满红绿细胞层」（除非逐 Patch 巡查）。

**TPS 数值**：ROI 摘要中的 **Mean TPS** 为 ROI 内相交 Patch 的 **细胞加权平均**：\(\sum (\texttt{patchPredTps}\times\texttt{numCells})/\sum \texttt{numCells}\)（见 `SelectionRoiPanel` / `cellWeightedMeanTps`）。与「仅计数离散阳性细胞个数」可能不完全一致，因 **`patchPredTps` 来自离线清单**，未必等于 `≥0.5` 阳性个数除以细胞总数。

## 2. 案例解释（Explanation）— 修订版正文（可直接替换原「案例解释」段落）

在常规数字病理阅片中，WSI 常为千兆像素级，有效组织碎片化并夹杂大面积空白；依赖反复平移缩放寻找组织会抬高时间成本与认知负荷。同一病例不同碎片亦可能出现 **表达异质性**，若仅使用全片单一汇总，易掩盖局部特征。

本系统在实现上采用 **「宏观热力引导 + 顺序 ROI 量化 + Patch 细读」** 的组合：

- **宏观**：在缩略图尺度对 Patch 中心做 **TPS 加权的 2D KDE**（见上节），以 **`multiply` 叠加**在组织底图上，并由工具栏开关；空白区域无 Patch 或贡献极低，组织密集且 TPS 权重高的区域呈现 **热点**，起到 **导航地图** 式引导，便于快速跳过空白、定位离散组织块。
- **中观–统计**：中列下部 **TPS Distribution Overview** 提供 **1% 分箱直方图** 与 **Hilbert 空间条带**，在划定 ROI 后切换为 **ROI 内子分布**，与全片坐标语义对齐；**Selection ROI** 仪表盘给出当前 ROI 的 **细胞加权 Mean TPS** 及细胞/Patch 占比等，支撑局部量化。
- **微观**：通过 **画廊点击或主视图 Patch 点击** 选中 Patch，在右侧加载细胞表，以 **cell_class / 概率图层** 复核模型输出；可选 **LLM 浮动助理** 基于当前上下文辅助归纳（不改变推理结果）。

**异质性对比**：在当前 **单 ROI** 设计下，对两块离散组织的 **TPS 对比** 通过 **先后两次框选 ROI 并分别读取 Selection ROI 与直方图状态** 完成；若插图需要「并排 ROI」，建议标注为 **操作流程示意图** 或 **两次会话的并列截图**，以避免与「双 ROI 同时激活」的误解。

## 3. 建议在论文 / 答辩材料中的用词一致性

| 避免过度承诺 | 建议表述 |
|----------------|----------|
| 「密度等值线」 | 「加权 KDE 热力图（栅格渲染）」或「热力图式密度可视化」 |
